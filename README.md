# Arduino 高性能遥控履带车项目 (Tracked-Vehicle-Project)

## 1. 项目简介
本项目旨在打造一台兼顾速度与稳定性的遥控履带车。不同于传统的玩具级套件，本项目采用了全金属底盘和大功率驱动模块，使其能够在草地、沙地等复杂地形下稳健运行，同时保持结构耐摔耐撞。

**核心目标：**
- **动力强劲**：采用 12V 370 减速电机。
- **操作简便**：使用经典的 PS2 无线手柄进行控制。
- **零焊接设计**：全模块化连接，适合快速组装与维护。
- **可扩展性**：基于 Arduino Uno 平台，方便后续加入传感器或摄像头。

## 2. 硬件清单 (Bill of Materials)

| :--- | :--- | :--- |
| 底盘 | 小R科技 铝合金履带底盘 (370电机版) | 1 |
| 主控板 | Arduino Uno R3 (Type-C) | 1 |
| 电机驱动 | BTS7960 43A 大功率驱动模块 | 2 |
| 遥控器 | PS2 无线遥控手柄 + 接收器 | 1 |
| 电池 | 3S 11.1V 2200mAh 航模锂电池 | 1 |
| 降压模块 | LM2596S 带数显稳压模块 (12V转5V) | 1 |
| 充电器 | B3 20W 平衡充电器 | 1 |

## 3. 系统架构 (System Architecture)
- **电源管理**：11.1V 锂电直供电机驱动，通过 LM2596 降压至 5V 为 Arduino 供电。
- **信号传输**：PS2 接收器获取指令，Arduino 进行逻辑解析，PWM 信号驱动 BTS7960 控制电机转速。
