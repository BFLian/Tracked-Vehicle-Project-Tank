# 硬件引脚定义表 (Pin Mapping)

本文档记录了 Arduino Uno 与各功能模块之间的物理连接关系。

## 1. 电源管理 (Power Management)
| 模块 | 连接引脚 | 目标 | 备注 |
| :--- | :--- | :--- | :--- |
| 电池 (3S) | XT60 | 降压模块 IN+ / IN- | 主供电 |
| 降压模块 | OUT+ / OUT- | DC公头 (Arduino) | 稳压至 5.0V |

## 2. 遥控系统 (PS2 Receiver)
| PS2 接收器引脚 | Arduino 引脚 | 颜色建议 | 备注 |
| :--- | :--- | :--- | :--- |
| VCC | 3.3V / 5V | 红色 | 检查接收器支持电压 |
| GND | GND | 黑色 | 公共地 |
| DAT | D12 | 棕色/橙色 | 数据输出 |
| CMD | D11 | 蓝色/黄色 | 指令输入 |
| SEL | D10 | 绿色 | 片选信号 |
| CLK | D13 | 白色 | 时钟信号 |

## 3. 动力系统 (Motor Drivers - BTS7960)
| 模块名称 | 功能引脚 | Arduino 引脚 | 备注 |
| :--- | :--- | :--- | :--- |
| **左驱动器 (L)** | RPWM / LPWM | **D5 / D6** | PWM 速度控制 |
| | R_EN / L_EN | 5V | 常开使能 |
| **右驱动器 (R)** | RPWM / LPWM | **D3 / D9** | PWM 速度控制 |
| | R_EN / L_EN | 5V | 常开使能 |

---
*注：接线前请务必确认 Arduino 已断电。*
